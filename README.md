# T-Shirt Product Page

A responsive, modern product listing page with:

- Size selection (S to XXL)
- Quantity selector with increment/decrement
- Modal-based size chart
- Scrollable recommended items
- Clean animations and hover effects


## Tech Stack

- HTML5 + CSS3
- JavaScript 
- Responsive Design

## How to Run

1. Clone this repo
2. Open `index.html` in your browser
